TRIMI

A Tri-Modal Manipulation Interface for Direct Demonstration, Joint-Level Haptic Teleoperation, and Robotic Execution.

One interface for collecting human demonstrations, teleoperating a robot hand with joint-level haptic feedback, and executing on the robot.

Paper Code Modes

Three Modes, One Interface

01

Direct Demonstration

The operator manipulates objects through the interface by hand to record demonstrations directly.

02

Joint-Level Haptic Teleoperation

The same device teleoperates the robot joint by joint, with haptic feedback returned to the operator.

03

Robotic Execution

The robot executes manipulation on its own using the same interface hardware.
